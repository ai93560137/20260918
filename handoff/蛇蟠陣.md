## b. 例行流程

### 每個交易日 12:00 HKT（Routine A）
1. `cd /home/user/20260918 && git pull origin claude/gifted-carson-v2tvhw`
2. `date -u +%s > .github/levels-trigger` → commit＋push → 觸發 `.github/workflows/fetch-levels.yml`（跑 `.github/scripts/fetch_levels.py`，commit `tradingview/data_external/levels.json` 與 `hsi_days.json`）。push 被拒先 `git pull --no-rebase`。
3. 每 20 秒 `git pull` 一次，直到 `levels.json` 的 `fetched_at` 是今天（約 3 分鐘）。
4. 檢驗：hsi 15000–40000、mgc 1500–6000、各日 hi>lo、`dates` 含最近完整交易日、`fetched_at` 是今天。
5. 用 `ArtifactData` 寫雲端庫（先 get/list 取 version 當 `if_version`；用 `batch`）：
   - 恒指指令台 https://claude.ai/artifact/Qovghgidoao32zWai3gffX ：`levels/hsi`（set：h1,l1,h2,l2,h3,l3,dates,quote,source,asof=fetched_at）＋ `levels/status`（update：note,last_write）
   - 黃金指令台 https://claude.ai/artifact/26ZLBsaqoMFKoAxsD7E1iw ：`levels/mgc`（同上＋`fut` 整個物件，期貨口徑供 MGC 掛單）＋ `levels/status`
   - 交接時版本：hsi v43／status v33；mgc v39／status v31（之後每寫一次 +1）
6. 真倉核對（見下「真倉核對」）。
7. `python3 .github/scripts/compose_tg.py` → 生成 `.github/tg_outbox.txt` → commit＋push → `send-telegram.yml` 自動發到用戶 Telegram。
8. 安靜完成，成功一句帶過；失敗／異常／真倉有變才詳報。

### 每個交易日 16:45 HKT（Routine B）
同上 1–6，之後：
- `python3 journal/update_forward.py`：用收市報價結算紙上倉位，追加 `journal/forward_test.csv`，寫 `journal/forward_line.txt`（非交易日自動標「休市不結算」）。
- `compose_tg.py`（含前向測試段）→ 連 `journal/` 一起 commit＋push。

### 真倉核對（兩個 Routine 都做）
- 憑證：環境變數 `GCP_SA_KEY` 存在時跑預設分支的 `.claude/hooks/session-start.sh`（`git show origin/claude/gcp-trading-v12-rewrite-bz75t2:.claude/hooks/session-start.sh > /tmp/x.sh && bash /tmp/x.sh`），它會輸出 `export GOOGLE_APPLICATION_CREDENTIALS=...` 等；存進 scratchpad 的 `gcp_env.sh` 再 `source`。**不要印出或 commit 金鑰。**
- 工具：預設分支的 `scripts/gcp_agent.py`（`git show ...:scripts/gcp_agent.py > <scratchpad>/gcpa/gcp_agent.py`），用 `python3 gcp_agent.py cat --object <物件>`。
- GCS 物件：`futu/risk/latest.json`（`run_hkt`、`positions[]` 含 code/qty/open_price）；`futu/pnl/latest.json`（`deals[]`，**時間是 UTC，+8 才是 HKT**）。
- 比對 `HK.HSI2610`／`HK.HSI2611`… 的手數與 `journal/position.json` 的 `hsi.real_seen`：
  - 不同 → 更新 `real_seen`（只寫手數、價格），在對話問用戶一句「富途大恒指由 X 變 Y（開倉價 Z），屬不屬蛇蟠陣人手？」
  - 用戶答「屬」才改 `hsi.real_pos`（整數；null＝沒有蛇蟠陣人手倉）。`compose_tg.py` 在 `real_pos` 非 null 且 ≠ 紙上 `pos` 時加一行「⚠️ 真倉」掛單。
  - 讀不到快照就略過，不打擾。

### 紙上觸軌反手（任何時候發現）
- 觸上軌（價 ≥ 上軌）且紙上空／觸下軌且紙上多 → 按**通道價**成交、滑價 0、每邊費用 55：更新 `journal/position.json` 的 `hsi.pos/entry/entry_date/realized/fees/note`，`journal/log.csv` 加一行，重跑 `update_forward.py`，commit＋push。
