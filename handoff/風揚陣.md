合併：PR 轉正式（`mcp__github__update_pull_request draft=false`）→ `gh api -X PUT repos/ai93560137/20260918/pulls/<n>/merge -f merge_method=squash -f sha=<完整 SHA>`

安全做法：`git merge origin/<預設>` 正常合併，或 `git read-tree -u --reset origin/<預設>` 後 commit，最後 `git diff origin/<預設> HEAD` 應為空。
