## 1. 負責什麼

- 金絲雀是**美股市場風險的天氣預報**:每日用前一個美股收盤算燈色,lag=1 只管下一個交易日起。**只預測波動,不預測方向**,不是交易策略、沒有持倉。
- 正式燈(手冊 §2):
  - 短期軸 = VIX9D − VIX:> 0 紅;−0.5~0 走平;其餘綠

  - 黃 = VVIX / MOVE / AXVI 任一 > 自身滾動 252 日 p90(窗口含當日)
  - 試用層(**無警報權,只記錄**):黃×2、深黃 VVIX p95、紅相對深度 p90、9D 對 3M 倒掛、黃 VHSI p90;觀察名單 W1(VVIX/VIX < p10)

### 3.2 07:07 例行核對(Routine,見 §4)

1. `git fetch origin claude/gcp-trading-v12-rewrite-bz75t2`,一律 `git show origin/…:<path>` 讀,不切換分支。
2. GitHub 工具 `actions_list`(list_workflow_runs,`canary_daily.yml`)看最新 schedule run 時間與 conclusion;`list_workflow_jobs` 看五個步驟。
3. 沒跑或失敗 → `actions_run_trigger`(run_workflow,`canary_daily.yml`,ref=預設分支)手動補跑,3–5 分鐘後再核;仍失敗讀 job log,回報最前面講原因。
