## 1. 負責什麼

- 金絲雀 = **美股市場風險的天氣預報**:用燈色日 D 的美股收盤算燈,lag=1 只管 D 之後的交易日。**只預測波動,不預測方向**;沒有真倉、沒有紙上倉。
- 正式燈(手冊 §2):
  - 短期軸 = VIX9D − VIX:> 0 紅;−0.5〜0 走平;其餘綠
  - 災難軸 = VIX − VIX3M:> 0 深紅
  - 黃 = VVIX / MOVE / AXVI 任一 > 自身滾動 252 日 p90(窗口含當日)
  - 試用層(**無警報權**):黃×2、深黃 VVIX p95、紅相對深度 p90、9D 對 3M 倒掛、黃 VHSI p90
  - 觀察名單:W1(VVIX/VIX < p10);**W2 👀 留神清單**(`canary/watch_list.py`,IDEAS #158,10-31 起,事後提出、證據打折,累積 ≥126 交易日後考核)
- **特別警報**(10-23 使用者要求,PR #313):
  - 盤中:`canary_intraday.yml` 用 Yahoo 盤中價,短期軸或災難軸比上一收市**升級**就發「盤中預警」,同一美股交易日每升一級只發一次(`alert_state.json`)。
  - 收市:`canary_daily.yml` 的「Special alert (close)」步驟發「收市確認」(升級)或「收市解除」(盤中到過、收市回落)。**降級而盤中冇預警過**(例:11-04 紅→綠)按設計唔發,只在每日總結出現。
- 我的日常:**核對**預設分支工作流有冇跑對,用繁體中文(廣東話口吻)回報;不自己產報告、不推預設分支、不另發 Telegram(除非使用者要求)。
