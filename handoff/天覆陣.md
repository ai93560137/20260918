## 5. 模式開關（使用者 10-20 確認：「龍飛陣，沒有硬鎖，這個概念可以刪除」）

唯一開關 GCS `xau/control.json`（冇網頁按鈕、冇免權杖連結；頁面只顯示）：
```json
{"mode": "RUN"|"PAUSE"|"STOP", "reason": "…", "set_by": "user"|"ladder", "set_at_utc": "…",
 "auto_reset_day": "YYYY-MM-DD"|null, "principal_hkd": <私人>, "equity_peak": <自動>, "alerts_sent": {"day": "…", "<key>": "…"}}
```
| 觸發（只計天覆陣自己嘅單；本金 = 整個 C 戶口淨值－信用，私人） | 動作 | 重置 |
|---|---|---|
| 當日 ≤ −3%（夜盤 −4.5%） | PAUSE：停開新倉，已有倉照管 | 紐約 17:00 換日自動 RUN |
| 當日 ≤ −6%（夜盤 −9%） | STOP：平天覆陣所有倉＋唔問 Claude | 紐約 17:00 換日自動 RUN |
| 戶口保證金水平 < 300%（夜盤 450%） | PAUSE | 回升即自動 RUN |
| 保證金 < 200%／< 150%、累計虧損 ≥ 25%、高水位回撤 ≥ 10%／20% | **只發 Telegram**，唔停唔鎖（每日每項一次） | — |
| 使用者設 PAUSE／STOP（`set_by: user`） | 照設 | **程式永遠唔自動改**，只有使用者改返 |

程式只會改 `set_by: ladder` 嘅模式；冇任何要人手解鎖嘅狀態。Ⓒ 減半已刪。
