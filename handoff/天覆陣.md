## 5. 設計草稿：模式開關同自動重置（10-20，等總指揮同使用者確認）

使用者話「硬鎖」概念可以重新諗；總指揮建議參考龍飛陣（日蝕到線 → 平倉＋停機，下一個交易日自動重置）。設計如下：

### 5.1 GCS `xau/control.json`（唯一開關，冇任何網頁連結可以改）
```json
{"mode": "RUN" | "PAUSE" | "STOP",
 "reason": "人話一句",
 "set_by": "user" | "ladder",
 "set_at_utc": "2026-10-20 12:00:00",
 "auto_reset_day": "2026-10-21" | null,     // 紐約交易日（17:00 ET 換日）；到咗自動返 RUN；null = 只有使用者可以改
 "principal_hkd": 20000,                    // 本金（私人，唔入 repo）；日蝕／硬止損基準
 "equity_peak": 0}                          // 淨值－信用 高水位（程式自動更新）
```
| 模式 | 效果 |
|---|---|
| `RUN` | 正常：每根 M1 問 Claude，可開可平 |
| `PAUSE` | 唔開新倉；已有倉照管（止損止賺照查，Claude 可以 CLOSE／UPDATE_STOP）。對應 Ⓑ |
| `STOP` | 即平所有天覆陣倉（模擬＝紙上平倉；真倉＝`close|all` 指令），之後唔問 Claude。對應 Ⓒ／Ⓓ |

### 5.2 邊個觸發、幾時重置
| 觸發 | 模式 | `auto_reset_day` | 點解 |
|---|---|---|---|
| 日蝕 Ⓑ（當日 ≤ −3% 本金；夜盤 −4.5%） | PAUSE | 下一個紐約交易日 | 同龍飛陣：一日嘅事，第二日自動重來 |
| 日蝕 Ⓓ（當日 ≤ −6%；夜盤 −9%） | STOP | 下一個紐約交易日 | 同上 |
| 高水位回撤 Ⓑ ≥ 10% | PAUSE | **null**（使用者解） | 唔係一日嘅事 |
| 高水位回撤 Ⓓ ≥ 20%、累計硬止損 −25% | STOP | **null** | 要人檢討先可以再開 |
| 保證金 Ⓑ <300%／Ⓒ <200%／Ⓓ <150%（新 EA 先有數據） | PAUSE／STOP／STOP | null | 保證金係戶口級，手動單都影響 |
| 使用者手動 | 任意 | 使用者自己填 | 用 gsutil／控制台改 control.json；**冇網頁按鈕、冇免權杖連結** |

規則：程式只會把模式**升級**（RUN→PAUSE→STOP）同按 `auto_reset_day` 自動返 RUN；永遠唔會自己降級。使用者設嘅 STOP（`set_by: user`）程式唔會自動重置，即使有 `auto_reset_day` 都會先核對 `set_by`。
Ⓒ「減半」喺模擬階段（固定 0.01 手）等同 PAUSE；真倉階段 EA 支援 `close|half` 先做減半。
