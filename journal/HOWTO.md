# 如何開「對帳專案」（journal/HOWTO.md）

本文件是給用戶自己看的操作指南：如何開啟並持續使用「每日截圖對帳」工作階段。
執行細則見 `journal/RULES.md`。

## 開專案（只需做一次）

1. 到 claude.ai/code（或手機 App）→ 在 `ai93560137/20260918` 倉庫新建一個工作階段，
   命名「交易對帳」；
2. 第一句話說：「切到 `claude/gifted-carson-v2tvhw` 分支，讀 journal/RULES.md，
   之後每天我上傳截圖對帳」（因為對帳文件目前在這條分支上；如果想讓它在預設
   分支，叫 Claude 開 PR 合併即可）；
3. 之後每天**重開同一個工作階段**（不要每天新建——同一個階段有連續記憶，
   對帳連續性最好），上傳三張截圖：
   - TradingView 圖（含右下角「今日操作指示」面板），
   - 富途目前持倉頁，
   - 富途當日委託/成交記錄頁；
4. Claude 會逐項核對、指出差異、給糾正指令，然後把結果寫進 `journal/log.csv`
   並 commit + push——每天留痕，週末自動彙總執行率。

## 每天的完整循環（約 5 分鐘）

早上收到 TradingView 推播 →（收市後或掛單後）開對帳階段傳截圖 →
得到「✅ 全部同步」或「⚠️ 第 X 項不符 + 怎麼改」→ 照改 → 完。

## 兩條保護機制

`journal/RULES.md` 裡特意寫了兩條保護用戶的規則：

- 任何模糊地帶一律記 `violation`（不會替用戶找理由開脫）；
- 缺席兩天以上會強制要求全量重核最新持倉。

連續兩週 100% 無違規，才算通過紀律驗證期、可以考慮加碼。

## 調整規則

要調整任何規則（手數、商品、寬容度等），在對帳工作階段裡直接說一聲，
讓 Claude 修改 `journal/RULES.md` 即可，不需要手動編輯。
