# 外匯新宇宙（路線 A）：G10 ＋ 新興市場貨幣的利差／價值／三因子籃子——預先登記與結果（forex_research/FX_EM_UNIVERSE_BACKTEST.md）

背景：G7 七個貨幣的利差、價值、動量、三因子全 ☠️（FX_THREE_FACTOR_BACKTEST.md）。學術上的外匯因子溢價主要來自**寬宇宙**
（Lustig–Roussanov–Verdelhan 2011 用 35 個貨幣；Menkhoff 等 2012／2017 用 48 個），利差與價值的橫截面分散度大得多，
新興市場高息貨幣是利差溢價的主要來源（也是崩跌風險的來源）。這輪把宇宙擴到 Dukascopy 有日線的新興市場與其他 G10 貨幣，同一套引擎重測。

**登記日期 2026-09-25；登記 commit 之後才跑數；每個檢定只跑一次；只修程式錯誤並揭露前後數字。**
價格數據由 Actions（`fetch_forex.yml` em1／em2 組）抓 Dukascopy D1／H1 買賣價，登記時**尚未到齊**；宇宙名單由下面的機械規則決定，數據到齊後填入第 0 節的表，

- 每個貨幣的參與月份 = 其價格、利率、REER（僅價值因子）都齊的月份；當月可用貨幣數 N_t，**多空各 k_t = max(2, round(N_t ÷ 4))**。

### 1. 共同設定（沿用 FX_THREE_FACTOR_BACKTEST.md 第 0 節，只列差異）

- 樣本 2003-06-01 → 2026-08-31；每對起點 = max(Dukascopy H1 起, 2003-05)。
- 價格：Dukascopy D1 買賣收市中價；點差 = 當日（賣收 − 買收）× 2 的 20 日中位；每單位名義成交付半個點差 + 0.2 pip（pip = 該商品小數位 − 1）。
  新興市場點差寬（USDTRY、USDBRL 常見 0.1–0.3%），月換倉下每年成本仍應 < 0.5%，跑前用 `--inspect` 確認。
- **swap 加價分兩級**（新興市場 swap 加價比 G10 高，FX_COST_MODEL.md）：
  - 機構口徑：G10（EUR GBP JPY CHF AUD NZD CAD SEK NOK）0.25%、新興市場 0.75%
  - 零售口徑：G10 1.25%、新興市場 3.0%（零售券商新興市場貨幣 swap 加價常見 2–4%；假設值，寫死）
  - 敏感度（只報告）：全部 0%。
- 利率：每個貨幣主序列 `IR3TIB01`，缺的月份用 `IRSTCI01`、再用 `INTDSR` 補（同一套 `load_rates` 備援邏輯），延後一個月。
  TRY 的三個月拆息 2008 年後由即期利率接續（FRED 序列在 2008-04 停）。
- 價值：BIS 寬口徑 REER 5 年變動取負，延後一個月（同前）；沒有窄口徑的貨幣早期缺就缺。
- 動量：對美元 12 個月即期變動（同前）。
- 倉位：等權 1/k_t；美元中性；名義本金 1。成交同前。
- **門檻**：宇宙大半是新數據（新樣本），用 **t ≥ 2.5 ✅、1.5–2.5 🔍、< 1.5 ☠️**；另要：
  1. 隨機排序對照（500 次、同成本、同 k_t）97.5 百分位以上；
  2. **只用新增貨幣的子籃子（不含 G7）t > 0**——否則就是 G7 那 7 個在撐（而 G7 已判 ☠️）；
  3. **剔除 TRY 後 t ≥ 2.0**（土耳其里拉 2018 後的超高利率與崩跌是單一貨幣事件，不能靠它）；
  4. 2003–2012 與 2013–2026 兩段同號、最大回撤 ≤ 30%（新興市場波動大，放寬 5 個百分點）、正年 ≥ 60%。
  判決按機構口徑下；零售口徑並列報告。
- 已看過甚麼：G7 的全部結果；新興市場貨幣的價格與利率**從未在本倉庫看過**。
- 多重測試：本文件 **3 個正式檢定**（U1、U2、U3）。

### 2. 三個檢定

**U1：寬宇宙利差**——按三個月利率（延後一個月）排名，多高息 k_t 個、空低息 k_t 個。鄰域（只報告）：k_t = N_t ÷ 3；波動率權重。
**U2：寬宇宙價值**——按 −REER 5 年變動排名。鄰域：10 年平均偏離。
**U3（主）：寬宇宙三因子**——利差、價值、動量名次平均。鄰域：k_t = N_t ÷ 3；z 分數合成；兩因子版（利差＋價值）。
每個檢定另報告：只含新增貨幣的子籃子、剔除 TRY 版、單因子分解（U3）。

### 3. 判決規則與證偽

- 通過（✅）：機構口徑 U3（或 U1／U2）t ≥ 2.5 且第 1 節四個附加條件全過。t 1.5–2.5 且附加條件過 → 🔍。
- 上線後證偽：滾動 24 個月夏普 < 0，或單月虧損 > 回測最差月的 1.5 倍 → 停；每月記錄新興市場實際 swap（或 NDF／期貨基差）與模型差距，年化差距 > 0.5 個百分點 → 換口徑重算。
- 管道：新興市場現貨 CFD 的 swap 加價與週末缺口風險大，機構口徑要用 CME 期貨（6M 墨西哥、6L 巴西、RA 南非、PLN／HUF／CZK 期貨流動性差）或 NDF；上線前先核實每個貨幣有沒有可用管道，沒有的剔除再算一次（那是新登記）。
- 陣名：通過終審才議。

### 4. 跑數前的機制檢查（不看績效）

- 每個新商品：Dukascopy D1 起迄、H1 起（真數據）、小數位判定結果（`_done.json`）、近 3 年點差中位、與 Yahoo／FRED 的中位差（QC 報告）。
- 利率序列：每個貨幣主／備援序列的接續點有沒有跳點；TRY 2008 接續。
- `--inspect`：N_t 隨時間的變化、k_t、每年換手、每年點差成本、每年 swap 淨額。
- 隨機對照 500 次中位數與 97.5 百分位。
