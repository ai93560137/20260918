### 2. 測試 A：USDJPY 蛇蟠陣（新市場）

- **數據**：HistData M1 2000-05-30 → 2026-09-01 + Dukascopy 近期 M1 → 2026-09-23（`data_forex/USDJPY/`，券商時間），約 895 萬根
- **規格**：`donchian_backtest.py --mode sar --lookback 3`，觸價成交、每日每方向一次、永遠在場（規格書 1.2）；小數 3 位、1 pip = 0.01
- **成本**：主口徑 `--spread 0.010`（1.0 pip，一般 CFD）；副口徑 `--spread 0.017`（1.66 pip ≈ ECN + 佣金）。引擎點差固定、無滑點、無隔夜利息（USDJPY 隔夜利差大，長期持多有正 swap、持空負 swap——**本測試忽略**，判決時註明）
- **主指標**：逐筆 t 值（主口徑）。t ≥ 2 ✅、1.5–2 🔍 有希望、< 1.5 ☠️；另要 PF > 1.1
- **鄰域（不用來選參數）**：N = 1、2、3、5 全部為正才算平原；只有 N=3 好看 = 曲線擬合 → 降級
- **拆解**：按年正年數（≥ 60% 年份為正）、最好一年佔比（< 50%）、多空腿各自 PF、前 10 筆佔比、最長連虧、最大回撤
- **副口徑**：ECN 成本下 t 掉到多少——若主口徑 ✅ 而副口徑 ☠️，判決寫「只在點差 ≤ 1.0 pip 的帳戶成立」
- **對照**：買入持有不適用（外匯無自然多頭）；以 0 為基準，另看 2000–2012 與 2013–2026 兩段是否同號
- **已看過甚麼**：登記前只看過對照組（XAUUSD／NAS100 券商數據）與數據品質報告，**沒有跑過任何外匯商品的蛇蟠陣**

### 3. 測試 B：XAUUSD 樣本外驗證（現有 ✅ 的新證據，不是重測）

- **理由**：規格書的 XAUUSD ✅ 只有 4.1 年（2022-08 → 2026-09）；HistData M1 由 2009-03-15 起，**2009-03 → 2022-08 這 13.4 年是規格凍結後才拿到、與原樣本不重疊的獨立樣本**
- **數據**：`data_forex/XAUUSD/` 券商時間 M1，2009-03-15 → 2026-09-23
- **規格與成本**：sar N=3、`--spread 0.30`（規格書值），無滑點
- **先做數據一致性檢查**（不是測試）：重疊段 2022-08-03 → 2026-09-18 應與券商數據的 +2,659／PF 1.78 同號且 PF > 1.3；差太遠代表 HistData 與券商數據不可比，測試 B 作廢
- **主指標**：樣本外段（2009-03-15 → 2022-08-02）逐筆 t；門檻同上；另要 PF > 1.2、正年數 ≥ 60%
- **鄰域**：N = 1、2、3、5；**多空腿**：規格書說優勢集中多頭腿，樣本外若空頭腿明顯為負則只做多變體另計
- **判決寫法**：✅ 通過 → XAUUSD 由「4.1 年有希望」升為「17.5 年驗證」；不通過 → 原 ✅ 降為 🔍，並寫明 2009–2022 哪幾年輸
