### 1. 規則（照論文寫死）

- 事件集：`scheduled=1` 的 FOMC 公告日 t（美國交易日）。
- t−3 = t 之前第 3 個美國交易日（週末跳過；美國假日用 ZQ 有結算價的日子界定）。訊號 S = (100 − ZQ_next-month_settle_{t−3}) − target_{t−3}，單位基點；**次月 = t 所在月份的下一個月的合約**。
  - S ≥ +12.5 → 做多美元；S ≤ −12.5 → 做空美元；否則不交易。目標利率為區間時取上下限平均。
- 進場：t−2（t 之前第 2 個美國交易日）**14:00 ET**；出場：t 日 **公告時間前 5 分鐘**（14:00 公告 → 13:55 ET；14:15 公告 → 14:10；12:30 公告 → 12:25）。
  - 與論文的差異（揭露）：論文兩端都用 14:00 ET、公告 14:15；2013 起公告改 14:00，故出場提早到公告前 5 分鐘，進場時刻同步改為「與出場同一時刻」（t−2 的 13:55／14:10／12:25）。視窗長度仍為兩個交易日。
- 報酬（基點）：
  - **DOL**（論文物件）：四個貨幣 log 中價報酬等權平均，方向＝美元；用 bid-ask 中價（HistData 年檔只有 bid 時以 bid 代中價，點差對兩端對稱、對報酬影響 < 0.1 基點）。
  - **EURUSD 可交易腿**：做多美元 = 賣 M6E（EURUSD 下跌獲利）；毛報酬 = −方向 × ln(P_exit/P_entry)×1e4；**淨 = 毛 − 4.11**。
- 每次事件一個單位名義；不加倉、不提前出場、不隔夜以外的持有。

### 2. 檢定與門檻（寫死）

| 檢定 | 內容 | 門檻 |
|---|---|---|
| **H1（主，論文物件）** | 有訊號事件的 DOL 毛報酬（方向已乘）均值 t | **t ≥ 2.5** ✅ 門檻（FOMC 事件樣本第一次使用）；1.5–2.5 🔍；< 1.5 ☠️ |
| **H2（可交易性）** | 同一事件集的 EURUSD 淨報酬（扣 4.11）均值 > 0 且 t ≥ 1.5，**且 2016-01 以後子樣本（論文樣本外）均值同號為正** | 三條全過才算可交易 |
| 判決 | ✅ = H1 ✅ 且 H2 過；🔍 = H1 ≥ 1.5 或（H1 ✅ 但 H2 不過）；☠️ = H1 < 1.5 | — |

附加報告（不改判決）：升息腿／降息腿分開的均值與 t；方向命中率；最差單筆；剔除 2008 兩次離群（2008-10-29、2008-12-16）後的 t；回歸 DOL 對 S 的斜率、t、R²（對照論文 0.8／2.7／21.8%）；無訊號事件的 DOL 均值（論文：−5 到 −10 基點）；按年損益。

**統計力（登記時算，避免事後解釋）**：2008-01→2026-08 排定 148 次；2009–2015 零利率期幾乎無訊號；預估有訊號事件約 **30–40 次**（2008 降息、2015-12→2018 升息、2019 降息、2022–23 升息、2024–25 降息）。以論文 sd 61 基點、效應 25 基點：n=35 的期望 t ≈ 2.4；單一 EURUSD 的 sd 較大（估 70–80），H2 的 t ≥ 1.5 需效應 ≥ 18–20 基點。**所以：H1 用四貨幣 DOL 是為了統計力，H2 用 EURUSD 是為了可交易性；兩者缺一不可。** 若有訊號事件 < 25 次，報告但判決改為「樣本不足，🔍 待續」。

### 3. 雜訊對照與偽檢定（跑數同時做，不影響門檻）

- 訊號翻號置換 1,000 次（隨機指派每次事件的方向）→ H1 的 t 在置換分佈中的百分位。
- 時間平移偽事件：同樣的兩日視窗放在 t−12 → t−10（公告前兩週），同一訊號；期望 ≈ 0。
- 無訊號事件（|S| < 12.5）的 DOL 均值與 t（期望小且不顯著）。

### 4. 證偽、上線、帳本

- 若 ✅：以一張 M6E 紙上前向 12 次有訊號事件（約 2–3 年）；累計淨 < 0 即停。真倉前須 POSITIONS.md 登記並通知總指揮；每年約 5–8 次、每次 2 天，名義 14,000 美元對 5,700 本金 = 2.5 倍（鐵律 3 倍內）。
- 若 ☠️ 或 🔍：候選 3（MTV FOMC 當日空美元）共用此事件樣本，第二次使用門檻 t ≥ 3。
- 多重測試帳本新增：「FOMC 事件樣本（EURUSD＋三貨幣，2008→2026）」第 1 次使用（H1、H2 視為同一假設的兩個面向）。
- 不做：不掃門檻（12.5）、不掃視窗、不換貨幣對、不加 VIX／外匯隱含波動條件（論文說可預測性集中在高波動期——那是解釋，不是訊號；若要測是新登記）。

- ZQ 次月合約結算價：缺值天數、是否有 0／異常跳動；t−3 日期落在美國假日的事件數。
