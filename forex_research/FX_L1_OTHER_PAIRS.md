# L1 倫敦上午規律在其他外匯對？——預先登記與結果（forex_research/FX_L1_OTHER_PAIRS.md）

背景：EURUSD 在 09:00–12:00 UTC 平均下跌（FX_EXPLORATORY_SCAN.md 第三部分：毛 +1.88 基點／日、毛 t 7.15，HistData 跨來源與 2000–2003 樣本外確認）。
使用者要求測其他外匯對有沒有同樣規律。這是**確認性的方向假說**，不是海選：窗口固定 09→12 UTC，方向在跑數前按下面規則定死。

**登記日期 2026-10-12；登記 commit 之後才跑數；只跑一次。**

## 登記

### 假說與方向（寫死）

假說 H：倫敦上午歐元走弱、美元走強。據此：
- **預測做空的歐元交叉盤（5）**：EURGBP、EURJPY、EURCHF、EURAUD、EURCAD（賣出歐元）
- **預測美元走強的美元對（6）**：GBPUSD、AUDUSD、NZDUSD 做空；USDJPY、USDCHF、USDCAD 做多
- **無方向預測、只報告（9）**：GBPJPY、AUDJPY、CADJPY、CHFJPY、NZDJPY、GBPCHF、GBPAUD、AUDNZD、AUDCAD；另 USDSGD、XAUUSD、XAGUSD（美元計價商品）也只報告
- EURUSD 本身是發現樣本，不列入新對的計數，只作參照。

### 檢定

- **數據**：Dukascopy H1 買賣中價；樣本 = 該對 H1 第一個完整日 → 2026-08-31（EURAUD 2005-10、EURCAD 2004-10、NZDJPY／GBPAUD／AUDCAD 2006、AUDNZD 2006-12，其餘 2003-08）。價格取整點邊界前最後一根，窗報酬 = ln(P12 / P09) × 方向。
- **主指標**：預測方向的單邊毛 t。**「存在」判準**：毛 t ≥ 2.0（單邊 p ≈ 0.023）**且**樣本前後半（按該對日數對半）毛均值皆為預測方向。11 個方向性檢定不做多重校正（假說有先驗、且這是複製確認；結果同時列出 Bonferroni 後 t ≥ 2.6 的哪幾個）。
- **無方向對**：雙尾毛 t，|t| ≥ 3.0 標為「新線索」（9 對加 3 個商品）。
- **貨幣層面分解（七大，每日一次最小二乘）**：以七個美元對的窗報酬解出八種貨幣的漂移（總和為零的約束：c_USD = −Σr/8，各貨幣對美元 c_k = r_k + c_USD），報告每種貨幣的平均漂移（基點）與 t——回答「是歐元特有，還是美元普遍走強」。
- **跨來源與樣本外**（只對「存在」的對自動執行，不另作選擇）：HistData M1 同期毛均值與逐日相關；H1 起點之前的 HistData M1 樣本（EURGBP／EURJPY／EURCHF／EURAUD／GBP\*／USD\* 約 2000–2003 起）預測方向單邊 t ≥ 1.65。
- **淨經濟性**（只對「存在」的對）：成本 = (s_9 + s_12)/2（該對該年該小時相對點差中位）＋ 0.4 基點佣金；報告淨均值、淨 t、淨夏普。
- **組合**：對「存在」的對，等權（各 1/n）做空／做多，報告組合毛、淨年化與夏普、與 EURUSD 單獨的相關係數（是不是同一個賭注）。

### 判決規則

- 這是線索複製，不給 ✅。若 ≥ 3 個新的對「存在」且貨幣分解顯示歐元漂移顯著為負 → 結論「歐元特有的倫敦上午賣壓，可用多對表達」；
  若只有美元對存在、歐元交叉不存在 → 「美元普遍走強」；若都不存在 → 「EURUSD 特有」。
- 帳本：H1 外匯日內樣本延用探索性掃描；本檢定 11 個方向性檢定＋12 個報告用格。

## 結果（2026-10-12 跑數；登記 commit 99853d6d 之後；只跑一次）

輸出：`forex_research/fx_exploratory/L1_other_pairs.json`、`L1_other_pairs.log`；程式 `scripts/fx_l1_other_pairs.py`。

### 結論先講

1. **方向上，規律不是 EURUSD 獨有**：11 個方向性預測中 **9 個達到登記的「存在」判準**（預測方向毛 t ≥ 2.0 且前後半同向）；只有 AUDUSD（t 1.79）與 USDCAD（t 0.75）不成立。
2. **貨幣層面分解顯示：主角是歐元走弱，其次是美元走強**（歐元相對七大籃子 **−1.11 基點／日、t −6.75**；美元 +0.77、t +4.37；加元 +0.59、t +3.18；其餘貨幣不顯著）。
3. **但沒有任何一個新的對可交易**：這些對的毛漂移只有 0.2–1.7 基點，成本卻是 1.1–3.1 基點（交叉盤與小貨幣點差大），**淨損益全部為負**（−0.26 到 −2.2 基點／日）。
4. **九個「存在」的對合成一個組合，等於 EURUSD 的重複**：與 EURUSD 的淨損益相關係數 **0.97**（它們是同一個「−歐元＋美元」賭注的三角換算），組合淨 −0.67 基點／日、夏普 −1.00。
   所以 EURUSD 是這個規律**唯一值得交易的表達方式**（點差最窄、毛漂移最大）。

### 4. 組合（九個「存在」的對等權，扣成本）

毛均值 1.03 基點／日；淨均值 **-0.673** 基點／日、淨 t -4.64、淨夏普 -1.0；年化波動 1.7%；與 EURUSD 淨損益相關 **0.97**。
三角關係使得「賣歐元的交叉盤＋買美元的美元對」加總 ≈ −5 歐元 + 4 美元 + 澳元 + 加元 − 紐元，與 EURUSD 做空幾乎同一個賭注，但成本是它的 2–3 倍。

### 5. 判決

| 問題 | 答案 |
|---|---|
| 其他外匯對有沒有同樣的倫敦上午規律？ | **有，但全是同一個「歐元賣壓＋美元走強」的三角換算**：9/11 方向性預測成立，歐元交叉盤全部同向 |
| 有沒有新的可交易標的？ | **沒有**：每個對淨損益為負；EURUSD 是唯一成本低於毛漂移的表達方式 |
| 有沒有新的線索？ | **沒有**（無方向 12 個標的無一達 |t| ≥ 3.0） |

### 6. 看過結果後的觀察（不是判決）

- 「歐元特有的倫敦上午賣壓」比「EURUSD 窗」更像規律的本質；它支持這是結構性的資金流（歐洲上午的歐元賣盤，例如出口商／機構的對沖或再平衡），而不是 EURUSD 單一數據的偶然。
- 如果有成本比 EURUSD 更低的歐元空頭載具（例如 6E 期貨，約 0.6 基點，與 IBKR 現貨相近），規律的上限仍是毛 1.9 基點／日。
- 加元走強（+0.59、t 3.18）是這次分解的意外，未在登記內；歸為新觀察，不當作線索（單項、淨成本 CAD 交叉盤點差 1.6–2.4 基點、不可交易）。
