# 預測高低位都出現後入市・1:2 RRR 離場：回測規格與核對手冊

2026-10-04，用戶策略：
1. 入場時間是預測高位、預測低位**都出現後**。
2. 出場是 **1:2 RRR**。

用戶選擇：
- 方向兩種都測（跟蛇蟠陣／反向回歸）。
- 止蝕放在日範圍九成邊，可以持倉多日。

之前的結果（`../snake_week/`、`../snake_day/`）全部保留，不受影響。

- 程式：`research/hsi_futures_range/hl_both.py`。數據、預測位、蛇蟠陣重建、紀錄格式沿用 `snake_week.py`。
- 核對：`hl_both.py --verify`，用同一個 `snake_week_verify.py`，另加 1:2 目標與觸發條件的檢查。
- 測試：`tests/test_hl_both.py`（人造 K 線 12 項）。
- 結果：`REPORT.md`；結論見 `../MONEY_REPORT.md` 第二之六節。

## 一、數據、預測位、蛇蟠陣
同 `../snake_week/README.md` 第一節、2.1、2.2。這裡用到的是**日**預測高位、預測低位，以及日範圍九成邊。

## 二、規則
| 項目 | 規則 |
|---|---|
| 觸發 | 同一個交易日內，預測高位（某根 high ≥ 預測高位）和預測低位（某根 low ≤ 預測低位）**都被碰到過**；第二個被碰到的那一根就是觸發 K 線 |
| 入市價 | 第二個是低位：min(預測低位, 該根 open)；第二個是高位：max(預測高位, 該根 open)；同一根兩個都**第一次**碰到（先後不知）：該根收市價 |
| 方向 S | 跟蛇蟠陣（觸發那根之前的持倉）；蛇沒有方向就不做 |
| 方向 F | 反向回歸：第二個碰到的是低位就買，是高位就沽；同一根兩個都碰到就不做（不知道最後碰哪個）；不理蛇蟠陣 |
| 對照 S0 | 跟蛇，每天第一根開市就入（不等高低位都出現）；止蝕、目標同 S |
| 止蝕 | 入市當天日範圍九成邊：做多 = 低位下限（昨收 − 分位(d, 0.95) × R̂），做空 = 高位上限；**入市後固定不動**（1:2 才準確） |
| 目標 | 入市價 ± 2 × 風險（風險 = \|入市價 − 止蝕\|） |
| 持倉 | 未到止蝕或目標就繼續，可以多日；S、S0 遇到蛇反向反手也平倉，F 不理 |
| 次數 | 要空手才入；每個交易日最多入一次；當天平倉後不再入 |
| 每根處理次序 | ① 持倉：開市越過止蝕 → 開市價離場（跳空）；開市越過目標 → 開市價止賺。② 盤中碰止蝕或蛇反手 → 取較差價。③ 碰目標 → 目標價。④ 空手且觸發 → 入市；入市那一根之後再碰止蝕當作止蝕（保守），否則碰目標當作止賺。用收市價入市的，該根之後的事留到下一根。 |
| 成本 | 每筆來回 3 點；1 張；恒指每點 HK$50、小型恒指 HK$10 |

## 三、輸出與核對
- 檔案格式同 `../snake_week/README.md` 第三節：`trades/S.csv`、`F.csv`、`S0.csv`、預測位、蛇反手、`manifest.json`。
- `--verify`：沿用 L1、L2、S1、T1 至 T5，另加兩項：
  - T3「2R 止賺」：離場價 = 入市價 ± 2 × 風險（或越過目標的開市價），而且該根碰到這個價。
  - T5「高低都現後才入」：入市那一根之前，兩個預測位未曾都被碰到；連這一根就都碰到了；入市價符合上表；止蝕全程沒有改動。
- 2026-10-04 結果：L1 3,354、L2 620、S1 121、逐筆 206 筆各類檢查，**全部通過**。
- 加入新檢查後，`snake_week`、`snake_day` 重新核對也全部通過。

## 四、限制
- 「高低位都出現」的日子少：559 個可交易日中只有 50 天（9%），所以 S、F 各約 40 筆，樣本很小。
- 其餘限制同 `../snake_week/README.md` 第五節。
