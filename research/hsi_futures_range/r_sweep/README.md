# R 測試：找「R 夠大、期望值為正」的組合（兩個數據來源）

2026-10-04，用戶要求：
1. 用蛇蟠陣分支的 8.5 年數據重跑。
2. 低勝率不重要，最緊要找到一個 R 夠大、正期望值的組合，所以 R 要再測。

## 一、數據：沒有 8.5 年，只有 4.1 年
- 蛇蟠陣規格書的「HSI1! 8.5 年」是 **TradingView 上的實測**，原始 K 線沒有存進 repo。
- 蛇蟠陣分支有的是 **HK50 差價合約**（`data/HK50_M15.csv.gz`），2022-08-05 → 2026-09-18，約 4.1 年。
- `hk50_cfd.py` 把它轉成風揚陣格式：
  - 券商時間 = 紐約時間 + 7 小時。冬令首根 03:15、夏令首根 04:15，換成香港時間都是 09:15。
  - MT5 用開市時間，轉成收市時間；交易日 = 香港 09:00 至翌日 09:00。
  - 假期的零星 K 線（少於 4 根，例如 2022-10-04）剔除；半日市保留。
- **跟恒指期貨（Futu）對比**（重疊 730 個交易日）：
  - 每日波幅相關 0.998、每日升跌相關 0.998。
  - 平均波幅 443 對 446 點；收市價差中位數 −22 點。
  - 15 分 K 時間重疊 98.7%。
- 扣除 HAR 預熱（60 日）和預測位所需（120 日），可交易期：

| 來源 | 可交易期 | 交易日 |
|---|---|---|
| `futu` 恒指即月期貨（Futu） | 2024-06-26 → 2026-10-02 | 559 |
| `hk50` HK50 差價合約 | **2023-05-02** → 2026-09-18 | 834 |

- HK50 多出 2023-05 至 2024-06 這一年多，是 Futu 版本沒有的**樣本外**期間（2023 年恒指下跌）。

## 二、規則
- 完全同 `../hl_signal/README.md`：
  - 兩個「高／低位已出現」訊號都亮，下一根開市入。
  - 九成日範圍止蝕（固定）；可持倉多日；S 跟蛇（蛇反手也平倉）、F 反向。
  - 對照 S0：跟蛇、開市就入。
- **只改止賺倍數 R**：1、1.5、2、3、4、5、8、無（不設目標，只靠止蝕或蛇反手離場）。
- 設定名：`<訊號>_<方向>_R<倍數>`，例如 `B_S_R3`。

## 三、輸出與核對
- `futu/`、`hk50/` 各有：
  - `REPORT.md`（每組 8 個 R 的期望值、R 倍數、勝率、RRR、t、回撤、前後半段、逐年）。
  - `manifest.json`（輸入、各引擎 SHA-256）。
  - `signals.csv`、預測位、蛇反手、`trades/*.csv`（每組每個 R 一份逐筆紀錄）。
- `r_sweep.py --source futu|hk50 --verify`：
  - 同 `../hl_signal/README.md` 第三節的檢查。
  - 結果：futu 逐筆 3,035 筆、hk50 逐筆 4,619 筆，訊號重算全部項目**全部通過**。
- 加入「不設目標」後，`hl_signal` 和 `hl_both` 的 2R 逐筆紀錄逐字不變。
- 單元測試：`tests/test_hl_signal.py` 18 項，包括不設目標、3R、HK50 時間換算。

## 四、重跑
```bash
python3 research/hsi_futures_range/r_sweep.py --source futu [--json 15 分 K 快取]
python3 research/hsi_futures_range/r_sweep.py --source hk50
python3 research/hsi_futures_range/r_sweep.py --source futu|hk50 --verify
```
