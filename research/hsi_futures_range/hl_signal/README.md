# 訊號版：「高位已出現」＋「低位已出現」都亮後入市・1:2 RRR：回測規格與核對手冊

2026-10-04，用戶確認「預測高低位都出現」指的是**訊號版**：系統判斷當天的高位已出現、低位也已出現，即網頁 🅰️🅱️🅲 兩邊都亮。
規則照價位版（`../hl_both/`）：跟蛇／反向、九成日範圍止蝕、1:2 RRR、可持倉多日。之前所有結果保留。

- 程式：`research/hsi_futures_range/hl_signal.py`。
  - 訊號用 `high_low_in.run_period`，與「高低位已出現」回測和網頁同一套定義，逐日前推。
  - 數據、預測位、蛇蟠陣、紀錄格式沿用 `snake_week.py`。
- 核對：`hl_signal.py --verify`（`snake_week_verify.py`，另加 G1、G2 訊號重算與觸發檢查）。
- 測試：`tests/test_hl_signal.py`（人造 K 線 13 項）。
- 結果：`REPORT.md`；結論見 `../MONEY_REPORT.md` 第二之七節。

## 一、訊號（只看當天，period = 一個交易日）
- **進度**：每根 15 分 K 收市時判斷一次；每邊只算第一次亮。

| 訊號 | 高位已出現（低位對稱） | 參數 |
|---|---|---|
| **B 機率法** | 之後再創新高的機率 = erfc(離高位點數 ÷ σ_剩 ÷ √2) < 5%；σ_剩 = R̂ ÷ 1.596 ÷ 昨收 × √(當天剩餘變異比例) × 收市價 | p = 0.05 |
| **A 耗盡回落** | 當天已走（最高 − 最低）≥ 0.8 R̂，而且收市離最高 ≥ 0.5 R̂ | α 0.8、β 0.5 |
| **C 時間點** | 16:30 那根收市時，離最高 ≥ 0.4 R̂ | 16:30、β 0.4 |

- 剩餘變異比例：由之前最多 250 天的各時段平方報酬估計（`high_low_in.build_days` 的 `rem`）。
- 觸發：同一交易日兩邊都亮過，取**較遲亮的那一根**。
  - B：559 個有預測位的交易日中有 460 天觸發。
  - A：133 天。
  - C：29 天。

## 二、規則
| 項目 | 規則 |
|---|---|
| 入市 | 觸發那根收市後，**下一根的開市價**（訊號在收市才知道）；觸發那根已是當天最後一根就不做 |
| 方向 S | 跟蛇蟠陣（入市那根之前的持倉）；蛇反向反手也平倉 |
| 方向 F | 反向：較遲亮的是「高位已出現」就沽，是「低位已出現」就買；兩邊在同一根亮就不做。C 兩邊必定在 16:30 同一根亮，所以 C_F 永遠沒有交易 |
| 對照 S0 | 跟蛇、每天開市就入（同 `hl_both` 的 S0） |
| 止蝕 | 入市當天日範圍九成邊（做多＝低位下限、做空＝高位上限），固定不動；止蝕不在正確一邊就不做 |
| 目標 | 入市價 ± 2 × 風險 |
| 持倉 | 未到止蝕或目標就繼續，可以多日；要空手才入、每天最多一次、當天平倉後不再入 |
| 每根處理次序 | 開市越過止蝕 → 開市價（跳空）；開市越過目標 → 開市價止賺；盤中止蝕與蛇反手同根 → 取較差價；再看目標 |
| 成本 | 每筆來回 3 點 |

## 三、核對（`--verify`）
- 沿用 `../snake_week/README.md` 第四節的 L1、L2、S1、T1 至 T5，另加以下幾項：

| 代號 | 檢查 |
|---|---|
| G1 | `signals.csv` 每個訊號：由原始 K 線重算當時的極值和離極值點數 |
| G2-A | 條件成立，而且是當天第一次（逐根重算之前每一根） |
| G2-B | 由 R̂、昨收、`rem`、收市價重算 σ 和機率，機率 < 5%（「第一次」由單元測試與 `high_low_in.run_period` 保證，核對程式不重算之前每根的 `rem`） |
| G2-C | 16:30 那根、離極值 ≥ 0.4 R̂ |
| T5 | 入市那根＝兩個訊號較遲那根的下一根，入市價＝開市價；F 的方向符合較遲亮的一邊；止蝕全程不變 |

- 2026-10-04 結果：G1 1,956、G2 1,956、L1 3,354、L2 620、S1 121、逐筆 438 筆各類檢查，**全部通過**。
- 第一次跑時，G2-B 因 `signals.csv` 只寫四位小數而失敗，已改為寫足精度後重跑。
- `snake_week`、`snake_day`、`hl_both` 用擴充後的核對程式重新核對，也全部通過。
