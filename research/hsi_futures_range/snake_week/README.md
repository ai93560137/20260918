## 二、規則（全部寫死，按這裡實作即可重現）

### 2.1 蛇蟠陣（照 `SNAKE_COIL_SPEC.md`，分支 `claude/gifted-carson-v2tvhw`）
- **蛇日**：日市（當天 09:00–16:59 的 K 線）屬當天。夜市（17:00 起，以及翌日 09:00 前）屬**下一個**風揚陣交易日。
- **通道**：上軌 = 前 3 個蛇日的最高，下軌 = 前 3 個蛇日的最低；每個蛇日開始時更新。
- **反手**：觸價（停損單）成交，升破上軌就做多，跌破下軌就做空。
  - 成交價：做多 = max(上軌, 該根 open)；做空 = min(下軌, 該根 open)。
  - 每個蛇日每個方向最多一次。持多時同一根先看下軌、持空時先看上軌。
- 輸出 `snake_flips.csv`：每次反手的時間、新方向（1 多／−1 空）和成交價。

### 2.2 風揚陣預測位（逐日／逐週前推，只用之前已完結的數據）
- **日**：
  - 比例：u = (當天最高 − 昨收) ÷ R̂；d = (昨收 − 當天最低) ÷ R̂。
  - 有 ≥ 120 天的比例才出預測位。
  - 預測高位 = 昨收 + 中位數(u) × R̂；預測低位 = 昨收 − 中位數(d) × R̂。
  - 範圍邊：高位上限 = 昨收 + 分位(u, q) × R̂；低位下限 = 昨收 − 分位(d, q) × R̂。q = 0.90（八成範圍）或 0.95（九成範圍）。
- **週**（ISO 週，按交易日日期分組）：
  - 基準價 = 這週第一個交易日之前那個交易日的收市價。
  - 週預測波幅 R_週 = 第一個交易日的 R̂ × √(這週交易日數)。
  - 比例和範圍邊的算法同日，只是用之前所有已完結的週（≥ 20 週）。
- **分位**：線性插值，等同 `numpy.quantile` 的預設方法。
- 輸出：`levels_daily.csv`、`levels_weekly.csv`。

### 2.3 入市（2 種）
| 代號 | 規則 |
|---|---|
| **A 跟蛇同時入** | 空手時，蛇在某根 K 線反手，就用**同一個反手價**跟入新方向（記為「蛇反手跟入」）。空手而蛇已有方向（例如止蝕後、週末平倉後、回測第一天），**下一個交易日第一根的開市價**入（記為「空手・開市再入」）。 |
| **B 等回調** | 空手而蛇（該根之前）做多：當天在預測低位掛買單。做空：在預測高位掛沽單。碰到就成交，開市已越過就用開市價。每個交易日最多入一次；同一根剛離場就不再入。 |

- 入市時止蝕必須在正確一邊（做多：止蝕 < 入市價），否則不做。

### 2.4 止蝕（2 種範圍）
- 做多：本週低位範圍下限；做空：本週高位範圍上限。q = 0.90 或 0.95。
- **新一週第一根**：
  - ①②③：止蝕**重設**為新一週的範圍邊，可收緊也可放鬆。
  - ④⑤：只收緊、不放鬆。
- 所有止蝕改動都記在逐筆紀錄的 `stop_path`。

### 2.5 離場（5 種）
| 代號 | 規則 | 蛇反向反手時平倉？ |
|---|---|---|
| ① 蛇反手 | 只靠止蝕和蛇反手 | ✅ |
| ② 週末平倉 | 加上：這週最後一個交易日最後一根收市平倉（不帶倉過週末） | ✅ |
| ③ 週目標 | 加上：碰到週預測高位（做多）／低位（做空）止賺。每週更新；目標不在有利一邊時當沒有 | ✅ |
| ④ 移動止蝕 | 入市後由第二個交易日起，每天第一根把止蝕收緊到當天的日範圍邊，只收緊不放鬆 | ❌（不理蛇反手） |
| ⑤ 移動止蝕＋蛇反手 | ④ 加蛇反手平倉 | ✅ |

- 平倉是因為蛇反手，而入市方式是 A：同一根、同一價跟入新方向，等於反手。

### 2.6 每根 K 線的處理次序（同一根同時發生幾件事時）
1. **當天第一根**：
   - 持倉：做新一週的止蝕重設或收緊；④⑤ 再收緊到日範圍邊；③ 更新週目標。
   - 空手（A）：蛇有方向就用開市價入。
2. **持倉中**：
   - (a) 開市價已越過止蝕 → 開市價離場（止蝕・跳空）。
   - (b) 盤中碰到止蝕，或蛇反向反手 → 兩者都有就取**對我們較差**的價。
   - (c) 碰到週目標 → 用目標價離場；開市已越過目標就用開市價。止蝕優先於目標。
3. **空手**：入市（A：反手價；B：預測位）。
   - **入市那一根**：之後再碰到止蝕，當作止蝕（保守）；沒碰到止蝕而碰到目標，當作止賺。
4. **②**：這週最後一根收市平倉。
5. **數據最後一根**：仍持倉就收市平倉（數據完結）。

### 2.7 成本與單位
- 每筆來回 3 點（蛇蟠陣規格：佣金 HK$55／邊 ≈ 2.2 點，加滑價）。
- 1 張、以指數點計；恒指每點 HK$50，小型恒指 HK$10。
- **風險** = |入市價 − 初始止蝕|；**R 倍數** = 淨利 ÷ 風險。

## 四、怎樣核對

### 4.1 一鍵核對（需要同一份輸入數據，`manifest.json` 的 SHA-256 要相同）
```bash
python3 research/hsi_futures_range/snake_week.py --verify      # 讀 GCS（要 GCP_SA_KEY），或加 --json 本地快取
python3 tests/test_snake_week.py                               # 規則單元測試（人造 K 線，不連網）
```
`snake_week_verify.py` **不重用模擬程式**，只用原始 K 線和紀錄檔互相對照：

| 代號 | 檢查 |
|---|---|
| L1／L2 | 用 `numpy.quantile` 重算每日、每週預測位，跟 CSV 比（誤差 ≤ 0.01 點） |
| S1 | 獨立重建蛇日和 3 日通道，每次反手價 = 通道價或跳空開市價，並在該根範圍內 |
| T1 | 入市價、離場價都在該根 K 線的最高最低之內 |
| T2 | 入市那根之後、離場那根之前，沒有任何一根碰到當時有效的止蝕（按 `stop_path`） |
| T3 | 離場原因與價格吻合：止蝕＝當時止蝕價（跳空＝開市價）；蛇反手＝同一根有反方向反手且價相同；週末平倉＝該週最後一根收市；週目標＝該根碰到該價 |
| T4 | 淨利 =（離場 − 入市）× 方向 − 成本；R 倍數 = 淨利 ÷ 風險 |
| T5 | 同一組交易不重疊；蛇反手跟入價 = 反手價；回調掛單價不差過預測位；開市再入價 = 當天第一根開市價 |

2026-10-04 結果：L1 3,354、L2 620、S1 121、T1 至 T5 各 2,721 筆，**全部通過**。
第一次跑時，核對程式抓到兩個問題，已改正後重跑：
1. 週目標在入市那一根之後才碰到，紀錄的價不在 K 線範圍內（14 筆）。
2. 紀錄只寫兩位小數，重算 R 時差 0.01（181 筆）。

## 五、已知限制
- **轉月不調整價差**：蛇蟠陣用的是 TradingView HSI1!，這裡用風揚陣自己的即月連續序列重建，轉月日的跳空可能令少數反手時間不同。
  同期重建的蛇蟠陣每筆 +76 點、勝率 40%、RRR 2.08，與它公佈的數字相近。
- **15 分 K 內的先後次序不知道**：一律用 2.6 節的保守規則。
- **期間短**：2024-06-26 至 2026-10-02，每組 69 至 228 筆；20 組同時比較，要小心「揀到好看的」。
- **只有一張、固定成本**：沒有模擬資金管理和保證金。
