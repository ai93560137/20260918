# 跟蛇蟠陣持倉多日＋風揚陣「日」預計範圍止蝕：回測規格與核對手冊

2026-10-04，用戶要求：週範圍止蝕太遠（平均約 1,300 點）幾乎用不上，改試近得多的**日範圍**。
其餘全部跟 `../snake_week/README.md` 相同：數據、蛇蟠陣、預測位、2 種入市、5 種離場、每根 K 線的處理次序、成本、輸出檔、核對方法。
**這裡只寫不同之處。**

- 程式：`snake_week.py --stop day`（同一個模擬函數 `simulate(..., stop_src="day")`）；核對：`snake_week.py --stop day --verify`。
- 測試：`tests/test_snake_week.py`「日範圍止蝕」一節。
- 結果：`REPORT.md`；結論摘要見 `../MONEY_REPORT.md` 第二之五節。

## 唯一不同：2.4 止蝕
| | 週範圍（snake_week） | **日範圍（本資料夾）** |
|---|---|---|
| 初始止蝕 | 入市那週的週範圍邊 | **入市那天的日範圍邊**：做多 = 昨收 − 分位(d, q) × R̂；做空 = 昨收 + 分位(u, q) × R̂ |
| 之後 | 新一週第一根：①②③重設為新一週的邊；④⑤只收緊，另每天收緊到日範圍邊 | **每個交易日第一根**（入市當天除外）：①②③重設為當天的日範圍邊（可收緊也可放鬆）；④⑤只收緊 |
| 平均離入市價 | 約 1,300 點 | 約 650 至 830 點 |

- q = 0.90（八成範圍）或 0.95（九成範圍）。
- ③ 的目標仍然是**週**預測高位／低位（每週更新）。
