# 早盤形態掃描：v1 → v2 研究（2026-10-14）

起因：v1（所有形態、固定目標、20 支 K 線）喺 ES／NQ／YM 回測平均每筆 +0.09R，太低。

## 方法

- 數據：`data/pattern_scan/`，22 隻產品 yfinance 日線（1995／2000 起，RTY 2017 起），`scripts/pattern_data.py` 抓。
- **只用 ≤ 2016 揀規則，2017 起只驗一次。**
- 穩健口徑：每筆 R 截喺 −3 至 +10（Yahoo 連續合約有轉月跳空同壞價，原始數會出 ±80R）、止蝕最少 0.5 ATR、扣成本 0.05 ATR 來回。
- 出場比較：固定目標（20 支）、移動止蝕 3 ATR（60 支）、移動止蝕＋保本。
- 研究腳本喺工作階段草稿，結論數字如下；正式規則照抄入 `scripts/pattern_scan.py`（`--backtest` 可重跑）。

## 結果（穩健口徑）

| 組合 | ≤2016 | 2017+ |
|---|---|---|
| 所有順勢延續形態（旗、突破、三角）全部產品 | −0.03R（7,277 筆） | +0.00R（4,770） |
| 做淡（任何延續形態） | −0.05R | −0.36R（t −10） |
| 外匯 | −0.07R | −0.27R |
| 利率 | −0.37R | +0.16R |
| 能源 | −0.18R | −0.03R |
| 指數 | −0.06R | +0.14R |
| **金屬（金、銀、銅）** | **+0.35R（t 4.0）** | **+0.15R** |
| 做好・區間上破＋牛旗・指數 | +0.06R（t 1.0） | +0.26R（t 3.7） |
| **做好・區間上破＋牛旗・金屬（v2 🟢）** | **+0.56R（585 筆、t 4.3）** | **+0.51R（410 筆、t 3.6）** |

- 出場：移動止蝕喺好倉突破明顯好過固定目標（贏嘅單揸得耐），所以 v2 改用移動止蝕。
- 回調反轉形態（吞噬、Pin、雙頂底、頭肩）同收窄 NR7／母子：兩段都冇優勢。
- 原始（唔截尾）v2 🟢 全期 1,121 筆、勝率 31%、+1.00R、t 6.4——受少數大單同壞價影響，以穩健口徑 +0.5R 為準。
- 按年：金屬＋指數做好突破 31 年得 16 年正，典型趨勢跟蹤：勝率約 30%，靠少數大單，要捱連續止蝕。

## 結論

1. 教科書形態本身喺日線幾乎冇優勢；有優勢嘅係「金屬喺上升趨勢做好突破＋移動止蝕」，即係趨勢跟蹤。
2. v2：🟢 只限呢個組合；其他形態降為 🟡、標明「歷史冇優勢」。
3. 指數做好突破測試期好但訓練期弱（t 1.0），未夠格 🟢；前向再睇。
4. 風險：選咗「金屬」係睇訓練期揀嘅，測試期都企得住，但只係 3 隻高度相關產品；黃金近年大牛市可能高估。
   前向判決照 `pattern_scan.py` 檔頭預先登記（🟢 ≥ 60 筆、平均 R > 0 且 t ≥ 2）。

## 2026-10-14 補充（見 `SUMMARY.md`、`SCORECARD_PATTERNS.md`）

同條件（金屬・上升趨勢・200 日線上）**隨機日入場**＋同樣移動止蝕，都有約 +0.44R；v2 🟢 +0.51R 同佢差唔顯著。
即係優勢嚟自趨勢跟蹤框架，突破／牛旗形態本身冇顯著加值。上面「結論 1」應理解為「金屬趨勢跟蹤有優勢」。
