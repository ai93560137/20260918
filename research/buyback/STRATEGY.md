# 回購宣告策略：新增或加碼回購授權後買入

狀態：**預先登記草稿**（尚未抓數據、尚未跑數）。回測時照本文件規格執行一次；
改任何參數都要先在本文件記錄修訂與理由，再跑數。

---

## 1. 選題邏輯

前三題（佩洛西、內部人買入、PEAD）都是在 S&P 500 大型股上找「公開訊號之後的漂移」，全部沒有可靠超額。
選第四題時，除了沿用「事前理由強、散戶做得到、數據乾淨」三個條件，再加一條：
**訊號要有「公司自己用錢表態」的成分**，不只是一則消息。

| 條件 | 回購宣告 |
|---|---|
| 事前理由 | 公司宣布回購後的長期超額報酬是經典文獻（Ikenberry、Lakonishok、Vermaelen 1995：宣告後 4 年約 +12%），解釋是管理層認為股價被低估，市場對這個訊號反應不足 |
| 散戶可執行 | ✅ 8-K 申報後隔天開盤買進，持有數月到一年，換手低 |
| 數據 | 🟡 沒有結構化欄位，要從 8-K 全文判斷「新增或加碼授權」並抓出金額；可做但要稽核 |
| 與已測策略的差異 | 內部人買入是個人用自己的錢；回購是公司用公司的錢，而且金額通常大很多 |

**事前要先承認的風險**
- **效應可能已經消失**：Fu 與 Huang（2016）發現 2003 年以後美國回購宣告的長期超額大幅減弱，甚至不顯著。
  前三題的經驗也顯示大型股很有效率，**這題很可能不過**。
- **價格數據只有 S&P 500**，而文獻中效果最強的是小型股、價值股。
- **授權不等於執行**：很多公司宣布後沒有真的買回。我們只看宣告，不看實際執行。

它仍然值得測：數據管線（8-K 抓取、成分股對照、回測框架）已經有了，增加的只是文字判讀，成本低；
而且規模門檻（授權金額 ÷ 市值）是其他三題沒有的維度，能分辨「象徵性」和「真的有份量」的回購。

## 3. 規則（主規格）

**事件判讀**（寫成程式，先稽核再回測）：
1. 8-K 全文（含 EX-99）出現回購授權用語：`repurchase`／`buyback`／`buy back`，搭配 `authoriz`／`approv`
2. 屬於**新增或加碼**的授權：如「authorized a new」「increase(d) … authorization」「additional $」；
   只提到既有計畫的執行進度（「repurchased X shares under its existing program」）**不算**
3. 抓出授權規模：美元金額（`$N million/billion`）或股數；同一份文件多個金額時取與授權用語同句者
4. **稽核**：隨機抽 100 筆由人工核對「是否為新增或加碼」與「金額」，兩者正確率都要 ≥ 90% 才能跑回測；
   不到就修判讀規則再抽 100 筆（判讀規則的修改不算調參，因為還沒看報酬）

**事件日 t0**：同 PEAD，`pre` → 當天；`regular`、`post` → 下一個交易日。
同一公司 180 天內多份只算第一份。

**訊號**：授權規模 ÷ 宣告前一日市值 **≥ 5%**（市值 = t0 前最近一次申報的流通股數 × t0−1 收盤）。
股數型授權換算成「股數 ÷ 流通股數」。

**進場**：t0 開盤買入（盤前申報的 t0 是當天；盤中、盤後申報的 t0 是下一個交易日，都不會用到申報前的價格）。
**出場**：持有 **252 個交易日**（約一年）後開盤賣出。不設止損，不看大市過濾。
**倉位**：所有持有中的部位等權；同時超過 50 檔時，新訊號依規模比例由大到小補到 50 檔。
**成本**：單邊 10 bps。

## 4. 判決門檻（跑數前寫死）

主要比較對象是**同期等權 S&P 500（point-in-time）**。

| # | 條件 | 門檻 |
|---|---|---|
| A1 | 逐筆超額報酬（vs 等權 S&P 500 同期）t 值，**按進場月份分組** | ≥ 2.0 |
| A2 | 組合月報酬對 SPY 的 CAPM alpha t 值 | ≥ 2.0 |
| A3 | 同日、同檔數隨機抽 S&P 500 成分股（200 次），**抽樣時配對 beta 五分位** | ≥ 第 95 百分位 |
| A4 | 鄰域：規模門檻 {2.5%, 5%, 10%} × 持有 {63, 126, 252} 日，共 9 格 | ≥ 6 格 t ≥ 1.5 |
| A5 | 2018 年後子期間的平均超額 | > 0 |
| A6 | 最大回撤 | ≤ SPY 的 1.5 倍 |
| A7 | 年換手 | ≤ 300% |

- **全過**：🔍 有希望，進入前向紙上交易。
- **A1 不過**：☠️，不調參數重跑。
- A3 改為配對 beta：PEAD 的經驗是隨機抽樣不控制 beta 時，高 beta 訊號會輕易通過。
- A5 改為 2018 年後：回測期從 2010 年開始，2018 年大約是後半段；2018 年稅改後回購金額大增，也是檢查重點。

**診斷（不影響判決）**
- **規模方向一致性**：規模越大，超額應該越高（按規模分三組）。
- **宣告前跌幅**：宣告前 6 個月報酬較差的一半應該較好（文獻中的「低估」訊號）。
- **與財報同時宣告 vs 單獨宣告**：同一份 8-K 含 Item 2.02 的，混有財報反應；分開看。
- 超額集中在持有期的哪一段（0–63、63–126、126–252 日）。

## 5. 實盤測試計畫（回測過了才做）

1. 每日收盤後由 GitHub Actions 抓前一日的 8-K，判讀回購授權並算規模比例，產生隔天開盤的買入名單。
2. Telegram 推送新訊號、到期要賣的部位、目前持股。
3. 紙上交易 3 個月，比較名單價與實際開盤價。
4. 報酬沒有明顯偏離回測分布後，才用小資金執行。
