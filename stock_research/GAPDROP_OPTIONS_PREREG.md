## 1. 假設

- **H1**：跳空大跌（開市已低過前一日最低）之後 21 日相對大市偏弱、實際波動較高 → 賣 95% put 的損益平衡 ρ\* **高過**盤中大跌。
- **H2（對立）**：盤中大跌（開市冇跳空）反彈較多 → 賣 put 較著數、賣 105% call 較差。
- 實際用途：如果 H1 成立，虎翼可以喺跳空大跌時要求較高 ρ（或者唔做）；成立與否都**唔即時改規則**，要另行登記前向驗證並經使用者確認。

## 2. 數據與宇宙

- 同 `bigdrop_options.py`：`options_stock.Panel`；美 S&P 500 PIT 1996-01 起、港恒指 PIT 2010-07 起；事件日當天係成分股先算。
- 開市、最高、最低價乘 AdjClose ÷ Close 換成調整口徑（避免除淨日假缺口）。開市價係正式時段開市（Yahoo 日線，唔計盤前）。
- 已知偏差同大跌研究：美股曾經成分股只 55% 有日線（倖存者偏差有利 put）。

## 3. 事件與分組（大跌日 t；前一日 t−1）

事件母體＝虎翼現行定義：AdjClose 報酬 ≤ −8%、收市 ≥ 5、之前 ≥ 315 日數據、同股 21 交易日內只取第一次、t 日收市入場（同 `bigdrop_options.Study.events`）。

**主分組（三組，互斥）**：
| 組 | 定義 | 意思 |
|---|---|---|
| A 完全跳空 | H_t < L_{t−1} | 全日都冇回補缺口 |
| B 跳空低開、盤中回補部分 | O_t < L_{t−1} 且 H_t ≥ L_{t−1} | 低開但日內曾升返前一日低位以上 |
| C 盤中大跌 | O_t ≥ L_{t−1} | 開市冇跳空，跌幅喺日內發生 |

**次分組（只報告，不參與判決）**：
- 隔夜佔比 = ln(O_t ÷ C_{t−1}) ÷ ln(C_t ÷ C_{t−1})：< 1/3、1/3–2/3、≥ 2/3
- 跳空幅度 L_{t−1} ÷ O_t − 1（只限 A＋B）：< 2%、2–5%、5–10%、≥ 10%
- 低開後走勢（只限 A＋B）：C_t > O_t（低開高走）vs C_t ≤ O_t（低開低走）

**敏感度**（同時報，不挑最好）：門檻 −6%／−10%；入場 t＋1 收市。

## 4. 量度（每組都報）

1. 事件數、佔母體比例、按年分佈
2. 超額報酬 5／21／63 日＝減同日 PIT 成分股等權平均（island_reversal.py v2 的基準）；平均、按月聚類 t
3. 21 日報酬：平均、中位、≤ −10% 比例、≥ +10% 比例
4. RVfwd21 ÷ RV63pre 中位與平方平均比
5. 賣 95% put、賣 105% call 的 ρ\*、ρ₂（BS σ = ρ × RV63pre，21 交易日，成本美 0.5／港 1.0 波動點；同 bigdrop_options）
6. 組間差：A − C 的超額 21 日差（兩樣本、按月聚類：同月兩組各自平均後相減再算 t）
7. 分段：美 2000–2012／2013–2026；港 2010–2017／2018–2025
8. 對照：全部大跌（母體）、隨機日（bigdrop_options 隨機對照）

## 5. 判決規則（寫死；以美股主分組為準、港股複驗）

- **H1 成立（跳空係有用過濾）**：美股 A 組 put ρ₂ ≥ 1.00（比母體 0.95 高最少一格）**且** A − C 超額 21 日差 t ≤ −2 **且** 兩個分段 A − C 差同號 **且** 港股 A − C 同方向（港 t 不設門檻，事件少）。
- **H2 成立（盤中大跌較著數）**：美股 C 組 put ρ\* ≤ 0.85 **且** A − C 差 t ≥ +2 **且** 分段同號 **且** 港股同方向。
- 兩者都唔成立 → **冇分別**：虎翼照用現行單一門檻。
- 港股方向相反 → 降一級為「不確定」，只准前向紙上記錄分組。
- 任何結果都唔覆蓋 BIGDROP_OPTIONS_PREREG.md 的判決。
