## 結論

1. **美指的波動溢價是恒指的 1.5–1.7 倍**，t 值加倍，ES 是 37 年裡 36 年為正的怪物。
2. **使用者現行的 NQ 月度 put credit spread 被同一流程驗證為真**（t=4.2、去頂 5% 仍正）——
   它在 NQ 能活而在 HSI 死掉的原因：底層溢價厚 + 漂移補貼大。
   ⚠ 平坦 vol 模擬高估 spread 實收（skew 讓保護腿更貴，同 §10.7 教訓）；
   實盤 credit 會低一些，但 t=4.2 的餘裕遠非 HSI 的 t=0.4 可比。
3. **同樣的結論梯度：跨式 ≈ 2.5–3 倍於 put spread**（溢價住在平值）。
   NQ 若改做 delta 對沖 ATM 跨式，月均毛收益約為現行 put spread 的三倍。
4. 規模可行性（NAV 80 萬 HKD）：標準 NQ 期權名義 ~US$490k 太大；

   且 micro 期指讓細對沖容易。待辦：實盤報價核定 micro 期權價差（複製 §10.8 第 0 步）。
5. 未做：美股實際 skew 下的 spread 重定價（需逐履約價 IV）、美元匯率暴露、
   與 HSI 部位的相關性（同月雙市場災難的疊加）。

**誠實拆解（按專案規矩自檢）**：
1. **止盈無意義**：對沖版跨式的月損益碰不到權利金的 50%（440 月零觸發）。
   「賺到 50% 就跑」是給不對沖裸賣方的建議，與我們無關。
2. **避開結算週（day14）更差**：少收 1/3 溢價，災難照樣在前兩週打到你。
3. **小尖峰逃生（+5）更差**：25% 月份被洗出去，鎖定會均值回歸的小 vega 虧損。
4. **止損的均值「改善」全部來自五大災難月**（2020-03 +18.7、2008-10 +10.3、
   2008-09 +9.1、2025-04 +6.4、2011-08 +5.6）；去掉這五個月後止損略差於持有
   （+0.748 vs +0.797）、切半前段也略差（+0.77 vs +0.81）。
   **所以它不是 alpha，是尾部保險**：正常月付約 0.05%/月保費（whipsaw：
   2024-08 −5.0、2018-02 −2.9），災難月把 −26% 截到 −8～−10%。
5. **模型偏袒止損，改善要打折**：常數 dollar-gamma 假設在災難月高估持有損失
   （真實 straddle 深度價外後 gamma 衰減，終值法算 −14%、路徑法 −26%，真值居中）；
   且尖峰時實際點差更寬，止損成交有額外滑價。方向可信，幅度看半。

**建議（待使用者簽收後才進 SOP）**：採 **部位止損 = 損失達 1× 權利金即平倉**

## MNQ 評估（2026-09-22，使用者問「MNQ 可以做嗎」）

技術上可行（同期貨賬戶、micro、同流程），**現階段否決**，四個理由：
1. **一組太大**：$2 × 30,782 = US$61.5k ≈ HK$48 萬 = **60% NAV**（MES 是 38%）
2. **單位 NAV 期望打平、尾部大 1.5 倍**：NQ 前瞻溢價已壓縮至 +0.6%/月
   → MNQ 期望 +0.36% NAV/月（與 MES 完全相同），但最壞月 −7.9% NAV vs MES −5.3%
3. **與 MES 零分散**：ES/NQ 同國同因子，災難月完全重疊（比 HSI/ES 的 +0.56 更高）
   ——同時做 = 98% NAV 名義、同一注加倍，違反相關性結論
4. **MNQ 期權點差未核定**（micro NQ 期權流動性通常又比 MES 薄一檔）

定案：規模階梯維持 1→2→3 MES，MNQ 不進階梯。使用者現行的 NQ put credit
spread（已驗證 t=4.2）若仍在跑：首月維持原狀不動，MES 實盤對板後再議

## Gamma 策略設計實驗室（2026-09-25，`gamma_lab.py`，HSI 278 月 + SPX 440 月）

使用者問「現在方向去設計 gamma 策略」。把 gamma 方向的設計空間全量了一次：

**A. 長 gamma（買跨式+對沖）：全滅。**
無條件長 gamma = 我們短倉的鏡像，年化 HSI −6.7% / SPX −11.7%（t −5.4 / −12.2）。
加「便宜波動率」過濾（spread≤0 / ≤−2 / 最低十分位）依然全部負期望
（t −1.6 ~ −2.5，勝率 16–29%）：IV 低於 HV 之後，RV 通常繼續跌得更快，
買便宜 vol 還是買貴了。

**B. 長 gamma 當尾部保險：不亮燈。**
災難月（短倉虧>1x 權利金）進場時 spread≤0 過濾器：SPX 7 個災難月只亮 1 個
（2008-10），2008-09/2011-08/2018-02/2020-03 全部進場時溢價為正。HSI 3 中 2，
但 2022-03 也漏。想靠「便宜時買保險」對沖自己的短倉——訊號不可靠，否決。

**C. 週度短 gamma（賣 5 天跨式）：唯一活口，生死掛在折讓 h。**
用 30 天波指近似週權 IV，對期限結構折讓 h 做敏感度（成本按 vega 減半假設
加倍：HSI 0.25 / SPX 0.115 vol 點）：

| h（30d IV − 週權 IV） | HSI 年化 | SPX 年化 |
|---|---|---|
| 0 點（幻想上界） | +18.5% | +26.5% |
| 2 點 | +7.2% | +15.2% |
| 4 點 | −4.1% | +4.0% |

最壞單週 −11~−12% 名義（與最壞單月同量級，但引信只有 5 天、每年 50 次抽籤）。
**結論：不能用近似數據決定。已在 `fetch_spx_chain.py` 加裝週權 IV 記錄儀**
（每日抓最近 4–10 天 SPX 到期的 ATM (c+p)/2 IV，與月權同格式記入
`weekly_iv_log.csv`），累積 2–4 週實測 h 分布後再裁決。恒指週權同理需要
富途截圖或 HKEX 抓取確認（週權產品碼與月權不同，未接）。

**設計判決（2026-09-25）**：長 gamma 系統性負期望，任何形態都不做；
週度短 gamma 是唯一值得繼續調查的方向，但即使 h 實測有利，它與現有月度
短倉是同一個風險桶（同標的、同短 vol），只能從同一份風險預算裡切，
且對沖頻率、每週結算的運營成本要一併計入。復核點：weekly_iv_log 滿 10 筆。

## 月度腿做錨（2026-09-25，`anchor_lab.py`，HSI 278 月 + SPX 440 月）

使用者問：虧損/對沖到某個層面時，市場在發生什麼？那時有什麼機會？
用倉位自身狀態做探針，量化「事件月的下一個月」：

| 事件（當月） | HSI 下月均 / t | SPX 下月均 / t | 下月進場權利金 |
|---|---|---|---|
| 基準 | +0.50% / +4.8 | +0.95% / +11.8 | 5.3% / 4.5% 名義 |
| 波指+5 點 | +0.38% / +1.2 | +0.87% / +3.5 | 6.6% / 5.7% |
| 波指+10 點 | +0.10% / +0.1 | +0.95% / +1.2 | 7.7% / 7.7% |
| RV壓過進場IV（頻對沖月） | +0.55% / +1.8 | +0.67% / +2.0 | 6.2% / 5.5% |
| 浮虧過半權利金 | −0.23% / −0.2 (n=12) | −0.95% / −0.6 (n=13) | 8.3% / 7.8% |

市況畫像：波指+10 月 = 指數 −6%、RV 35~38；止損等級月 = 指數 −8.6~8.8%、
RV 55~74（HSI 3 次 / SPX 7 次，約 1% 月份）。

**核心發現（反直覺）**：「危機後溢價肥所以加倉」是迷思。掛牌價確實漲
~50%（權利金 8% vs 5% 名義），但下月風險同比例放大——期望 % 不升，
HSI 餘震月甚至歸零；浮虧過半後的下一個月兩市場均值皆負（波動聚集）。
**機會不在加倉，在紀律**：同一手數自動收到 1.5× 點數、止損釋放的資金
恰好在權利金最肥時可按標準倉位重進新 ATM（重新置中）、壓力期週權期限
結構倒掛（記錄儀會捕捉）。餘震樣本不足以支持「跳過下月」規則（t≈0 非
顯著負），維持機械月度進場。
