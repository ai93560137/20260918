## 限制

- 申報只有金額區間，沒有股數；「金額加權」用區間中位數估計。
- 期權改成正股，報酬會遠低於她本人的槓桿部位。
- 2014 年前多為紙本掃描申報，無法自動解析；解析失敗的申報不在樣本內。
- 樣本小（每年約數十筆），結果的統計信心有限；過去績效不代表未來。
