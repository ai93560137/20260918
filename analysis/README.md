# 每日由上而下股票分析（analysis/）

由 `scripts/daily_topdown.py` 產生，`.github/workflows/daily_topdown.yml` 每個交易日早上
（美股收市數據更新後，約 08:00–09:30 香港時間）自動跑並發 Telegram。

| 檔案 | 內容 |
|---|---|
| `DAILY_TOPDOWN.md` | 最新一份完整報告 |
| `archive/<日期>.md` | 每日存檔 |
| `topdown_log.csv` | 每日三地的 200 日線／新高檔數、各板塊檔數、留下名單——**樣本外紀錄**，累積數月後用來誠實評估這套篩選 |
| `tg_topdown.txt` | Telegram 摘要 |

流程（2026-09-23 使用者指定）：

1. **國家**：港股 2800.HK、美股 SPY、日股 EWJ（美元計）——動能分數 = 3/6/12 個月報酬平均，**只排名、不篩選**
2. **個股 200 日線**：恒指／S&P 500／日經225 現任 point-in-time 成分股，昨天收市在 200 日均線之上的留下
3. **新高**：留下的股票，昨天收市價是否高於過去 12／9／6／3 個月的盤中最高價（跟報價頁「52 週高」同一把尺，依此順序顯示）；至少創 3 個月新高的留下
4. **按板塊統計**：每個板塊的檔數（各新高窗口分層計數），附板塊 6 個月超額動能排名作參考

200 日線用含股息還原收市（約等於富途「前復權」）；新高用原始最高價。港股名稱用港交所官方中文簡稱，日股代號顯示為 .JP。

**這是描述性篩選，不是回測過的交易訊號**：「200 日線 + 新高」沒有回測過；研究結論見 RESEARCH_HANDBOOK.md——只有港股行業動量
壓線過了預先登記門檻（🔍），美股不確定、日股 ☠️，港股個股動量單獨使用 ☠️。規則寫死在腳本的
`RULES`，不按每天結果調整。
